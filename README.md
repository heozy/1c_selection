Задача №4 "Старая карта"

**Запуск:**

Нужен Python 3, сторонние библиотеки не используются.

python3 solution.py

Программа читает карту из стандартного ввода (формат как в примере условия:
MAP, day_cost, entrance, vertex, edge, END). После этого она печатает команды
LOOK/MOVE/CLEAR/END и читает ответы судьи построчно.

**Проектные решения**

- Осмотр и переходы бесплатны, поэтому сначала обходятся все залы, до которых можно дойти по целым ходам, и осматриваются все ходы из них.
- Платная только расчистка. Кандидаты - известные обвалившиеся ходы из посещённых залов в непосещённые.
- Выгода от расчистки оценивается как ожидаемая ценность залов за ходом. Вероятность дойти до каждого зала считается как произведение вероятностей на самом надёжном пути через ещё не осмотренные ходы (алгоритм Дейкстры по максимуму произведения).
- Расчищается ход с наибольшей оценкой, если она строго больше day_cost. Иначе экспедиция завершается. После расчистки обход повторяется от входа.
- CLEAR можно вызвать из любого зала, как в прогоне 2 условия.
- Карта считается корректной, проверок ввода нет.
